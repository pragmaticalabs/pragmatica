## Structural observations from original audit

1. **The "warn-then-pass" demotion pattern is institutionalized.**
   Status: **MOSTLY DONE**. The 11-observability suite (the platonic form per the audit) has been fully rewritten with strict `log_fail`/`assert_*` paths.    Status: **DONE**. Repo-wide grep for `-lt 500` returns zero matches in `aether/tests/integration/`. The 16-occurrence pattern is eliminated.    Status: **MOSTLY DONE**. `api_delete`, `api_get`, `api_post`, `node_api_get`, `node_api_post` all route through `_api_call`. `cloud_ssh` invocations in `restart_all_nodes` cloud branch capture stderr explicitly. `remote_exec` in `container_running` captures stderr.    Status: **DONE**.
