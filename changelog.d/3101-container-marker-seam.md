### Changed (2026-11-12 — #3101: ContainerLabelInspectorTest assumed the build host is not a container)
- **`ContainerLabelInspector.inspectSelfLabels` read the host's real `/.dockerenv`**, so its test failed in any build environment that is itself a container. The marker path, Docker socket path and HOSTNAME now enter through a package-private overload; the public entry still uses `/.dockerenv`, `/var/run/docker.sock` and `$HOSTNAME`. The tests run against a `@TempDir` and a local Unix-domain socket and no longer read the host. `[verified: aether/node/src/test/java/org/pragmatica/aether/node/labels/ContainerLabelInspectorTest.java]`
