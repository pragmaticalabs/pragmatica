### Fixed
- A governor announcement that equals the committed one (governor, member list, address, term and epochs) is no longer committed again when a SWIM membership edge asks for it (#2542). It had been the bulk of the core's commits: a median 91% of an event's mutations, about 150 for one worker crashing at N=50. The governor's 30 s re-announce timer still re-commits it, so `announcedAt`, the freshness window the core reads and the sweeps that run on each committed announcement keep their cadence. `GovernorAuthorityMessage.Request` gains a `refresh` flag, set only by that timer.
