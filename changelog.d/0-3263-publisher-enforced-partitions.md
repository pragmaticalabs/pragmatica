### Fixed (2026-11-14 — #3263: stream publisher routed by the declared partition count)
- **A stream publisher routed keys by the partition count its slice declared, not the count the existing stream enforces** (#3263). Declared higher than enforced, appends to partitions at or above the enforced count failed `PartitionOutOfRange`; declared lower, keys mapped to different partitions than every producer using the enforced count, breaking per-key order with no error. The publisher now takes its count from the stream this node holds (the one `STREAM_CONFIG_CHANGE_NOT_APPLIED` says keeps being enforced) and logs a warning that the declared count was not applied. The declared count is used only while this node holds no entry for the stream. [verified: `StreamPublisherEnforcedPartitionsTest`]
