### Fixed (2026-11-24 — #2798: a shared step interface with no static factory became an UNRESOLVED slice dependency)
- **The slice processor refuses a dependency that is not a slice** (#2798). A factory parameter that is not a resource and not a plain-interface step (no static factory) was classified as a slice dependency, so the generated factory and manifest carried an invented `<base>-<kebab(name)>:UNRESOLVED` coordinate: Terra failed at assemble time ("Missing dependency or cycle"), Aether at deploy time, with `generate-blueprint` only warning. Such a dependency is now a compile error naming the parameter, unless it carries slice evidence: the `@Slice` annotation or an entry in `slice-deps.properties`. [verified: `SliceProcessorTest#nonSliceInterfaceWithoutFactory_*` (red on the old processor)]
