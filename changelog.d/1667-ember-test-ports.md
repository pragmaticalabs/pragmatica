### Fixed (2026-09-29 — #939, #1189, #1667, #466: tests that failed on a port or a daemon they never chose)
- **Ember cluster tests no longer fail when another process takes a probed port before the cluster binds it (#1667).** One shared helper, `EmberTestPorts`, replaces eleven copies of a probe-then-release port picker. The copies had also probed each node's SWIM UDP port at the wrong offset. Starts now retry on a fresh block, a bounded five times, when the start fails on a bind collision; any other start failure fails at once. [verified: `aether/ember/src/test/java/org/pragmatica/aether/ember/EmberTestPortsTest.java` — a port taken between probe and start; with a single attempt it goes red]
- **`EmberClusterForeignAdmissionTest` (#1189), `EmberClusterPartialStartFailureTest` (#939) and the two SWIM start-failure tests no longer bind fixed ports.** Under CI's module-parallel reactor those could collide with another module's test, and the three start-failure tests' own failure mode IS a bind failure.
- **The sql-splitter differential tests skip when Docker is unavailable instead of erroring (#466).** The eager `@Container` started before the `assumeTrue` guard; `@Testcontainers(disabledWithoutDocker = true)` now skips the class first. With Docker unreachable, the MySQL and Postgres classes went from 2 errors to 16 skipped.
