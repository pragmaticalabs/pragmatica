### Fixed (2026-10-18 — #2299: a fresh backfill on a fast failover raises HISTORY_MISSING falsely)
- **A replica that caught up from offset 0 into a partition it had not materialized yet dropped the source's owner-epoch history**, so the next live append raised `HISTORY_MISSING` for a copy that holds the source's whole history. The catch-up installed the source's slice before the page's first append created the log, so the install landed on nothing and the records were written unattributed.
- The install now materializes the partition through the same resolution the page's first append uses before it records the slice, so the history is installed onto the log the page is written into. A partition this node cannot materialize still installs nothing, and the page's first append returns the same refusal. `[verified: aether/aether-stream/src/test/java/org/pragmatica/aether/stream/CatchUpInstallsOntoMaterializedLogTest.java]`
