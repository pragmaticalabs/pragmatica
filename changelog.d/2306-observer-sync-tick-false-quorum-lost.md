### Fixed (2026-10-19 — an observer going passive no longer raises a false CRITICAL QuorumLost, #2306)
- **A joining observer (such as an auto-heal replacement) reported a CRITICAL `QUORUM_LOST` although no voter had lost quorum.** A sync-retry tick queued behind its state adoption found only a voter's `Active` state settled, moved the observer from `Observing` back to `Syncing` and published PASSIVE, which the application layer treated as quorum loss and answered by quiescing routing. `RabiaEngine.doSynchronize` now treats `Observing` as settled at both of its guards. [verified: `RabiaObserverStaleSyncTickTest`]
- **`QUORUM_LOST` is a statement about voters.** A PASSIVE on a node that is not in the installed voter roster (an observer) raises no `QUORUM_LOST`: it raises the WARNING `OPERATOR_WARNING` code `observer-consensus-lagging`, and the INFO recovery `observer-consensus-resumed` on every exit from lagging: the engine reports the observer observing again (new `ConsensusObserving` event, routed as `ObserverResumedNotification`), the observer is promoted to a voter (ACTIVE), it is removed from the cluster, or it shuts down. A crash publishes nothing from the node itself; its `NODE_FAILED` supersedes the warning. An unknown roster counts as a voter, so a cluster that never formed still reports its loss. This covers every way an observer can leave `Observing`, a catch-up resync of a far-behind observer included; routing on the observer is still quiesced. A voter's loss of quorum is unchanged. [verified: `ClusterEventAggregatorTest`, `SelfIsVoterProbeTest`, `EmberObserverQuorumLossWiringTest`]
- The operator-warning catalogue test now requires every WARNING or CRITICAL code to have a recovery code; the 23 codes shipped before the rule are listed explicitly and the list may only shrink. [verified: `OperatorWarningCodeTest`]
- The topology quorum edge counts installed voters only (defence in depth: it no longer relies on its feed being pre-filtered; the Aether runtime already filters the membership view to the installed voters, and that filter is now pinned by a test). [verified: `TopologyObserverVoterQuorumTest`, `MembershipViewFeedExcludesNonVotersTest`]
