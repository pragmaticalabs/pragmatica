### Changed (2026-10-18 — #2226: generated JSON codecs for slice payloads, replacing the Jackson path)
- **Value objects on slice HTTP are now unwrapped:** a single-component record is written as its bare value, not `{"value": ...}`, and decodes through its own factory. A refusal from the factory is a 400. The slice-route Jackson fallback applies the same rule through `JsonMapper.valueObjectJsonMapper()`. `defaultJsonMapper()` is unchanged. `[verified: jbct/slice-processor-tests/src/test/java/com/example/wireform/GeneratedRouteWireFormTest.java, integrations/json/jackson/src/test/java/org/pragmatica/json/ValueObjectModuleTest.java]`
- **Request bodies decode strictly.** Required fields are enforced, and `null` is rejected for non-`Option` fields. Skipped unknown values are validated against the full grammar. Invalid UTF-8, a BOM, lone surrogate escapes, non-canonical UUIDs and nesting deeper than 1000 levels are rejected. `[verified: integrations/serialization/json-tests/src/test/java/org/pragmatica/serialization/json/tests/StrictDecodingTest.java]`
- **`SliceCodec.writeString` now uses the JDK UTF-8 encoder.** It is byte-identical to the previous output except for malformed UTF-16, where Netty wrote invalid UTF-8. `[verified: integrations/serialization/api/src/test/java/org/pragmatica/serialization/SliceCodecTest.java]`
