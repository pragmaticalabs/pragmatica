### Removed (2026-10-22 — #494: the management dashboard)
- **The web dashboard is removed entirely.** The `aether/dashboard` module (static app and `StaticFileHandler`), the node's serving of `/`, `/index.html`, `/css/**`, `/js/**` and `/vendor/**`, and Forge's web UI on its port (8888) are gone (owner rulings of 2026-10-21). A new dashboard will be written from scratch, spec-first, and is not a 1.0 gate; until it lands the CLI and the Management API are the supported operator surfaces. A path no route matches on the management port still answers `404` with the body `File not found: <path>`. Forge no longer opens a browser at startup, and a non-`/api/` path on Forge now answers `404` with a JSON error naming the path. [verified: `ForgeRequestHandlerTest`, `ManagementServerSecurityCouplingTest.unmatchedPath_isAnswered404FileNotFound_andFormerDashboardPathsServeNoAsset`]
- **`/ws/dashboard` is removed** from the node and from Forge. The node keeps `/ws/status` and `/ws/events`; Forge no longer serves any WebSocket.
- **Forge routes that only fed the dashboard are removed:** the proxies `/api/alerts/*`, `/api/traces*`, `/api/observability/*` and `/api/metrics/history`, and the reads `/api/slices/status`, `/api/slices/topology` and `/api/cluster/metrics`. Forge's status (`/api/nodes/status`, `/api/nodes/metrics`, `/api/forge/status`, `/api/events`), chaos, load, simulator and deploy routes are unchanged. The `dashboard_port` key in `forge.toml` and `FORGE_PORT` still name Forge's API port.
- **The `[timeouts.observability] dashboard_broadcast` key is removed.** It was parsed and never read. A config file that still sets it loads unchanged. [verified: `aether/aether-config/src/test/java/org/pragmatica/aether/config/ConfigLoaderTest.java` `loadFromString_retiredDashboardBroadcastKey_isIgnoredAndTheSectionStillApplies`]
- **Alert threshold evaluation is not affected.** It lived in the dashboard's metrics publisher and never depended on a connected client; the class is now `AlertThresholdEvaluator`, started by `ManagementServer` as before, and `AlertManager.checkThreshold` no longer returns the WebSocket alert envelope. [verified: `AlertingReachesOperatorTest`, `AlertThresholdEvaluatorEvaluationPathTest`, `AlertingWiringLivenessTest`]
- Docs: the dashboard pages and sections, the Forge dashboard walkthroughs, feature-catalog rows 51 and 58, and `dashboard-ui-spec.md` are removed or rewritten; `CLAUDE.md` invariant 1 reads REST, CLI, docs until the new dashboard lands.
