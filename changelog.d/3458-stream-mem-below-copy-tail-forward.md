### Added (2026-11-22 — #3458 stream-mem M-9f: a `BelowCopyTail` read is forwarded once to the owner)
- **A copy that does not hold the range a non-owner reader asks for answers `BelowCopyTail`; the router that made that LOCAL read forwards it ONCE to the owner, and the owner's answer is the read's answer.** `StreamReadRouter.readValidated` forwards it to the HRW owner as it does `PARTITION_NOT_LOCAL`. `ForwardingReadRouter` forwards it from the first local read of each arm (GOVERNOR not behind the owner, NEAREST with and without a registry, ANY_REPLICA with no fresh peers), to the committed owner when a committed record names another node, else to the HRW owner. A `BelowCopyTail` that came back from a forward is never forwarded again; with no target (the owner is this node) or no forward client the original `BelowCopyTail` surfaces (503, retryable), never `PARTITION_NOT_LOCAL`. Only the type `BelowCopyTail` is keyed, never `CursorExpired`. No wire change: the existing forward calls carry it. Nothing raises `BelowCopyTail` in production yet (M-2r-1), so the arm is dormant.
