### Fixed (2026-09-14 — #1078: `AetherNode.stop()` never shut down the node-owned storage instances)
- **`StorageInstance.shutdown()` — "graceful shutdown: drains pending writes (write-behind) and releases resources" — was called by nothing on the node.** `AetherNode.stop()` stopped loops, schedulers, the stream runtime, servers, the invoker and the cluster node, and none of the three instances it owns (`content`, `artifacts`, `streams`), so a node stop was not graceful for storage: the path that exists for draining a write-behind queue was never taken. `stop()` now shuts down every `storageSetups` instance **after `sliceInvoker.stop()`** (the writers are stopped) **and before `clusterNode.stop()`** (a DHT tier can still be reached while draining), one instance's failure logged and never skipping the cluster stop behind it. [verified: `AetherNodeStorageShutdownTest` (`aether/node`) — a node assembled with the boot fixture, a log4j appender on `DefaultStorageInstance`'s logger: zero `Storage instance '…' shut down` lines before `stop()`, exactly `content`, `artifacts`, `streams` after; red at the base with `Expecting actual: []`; deleting the `shutdownStorage()` call from the chain reddens it]
- **What the drain does today, honestly:** every node instance is built write-through (`StorageFactory` calls the `storageInstance(name, tiers, metadataStore)` overload, which fixes `WritePolicy.WRITE_THROUGH`; repo grep for `WRITE_BEHIND` outside `integrations/storage`: none), so on a shipped node `shutdown()` deactivates no queue — it is the hook that makes a future write-behind tier drain, and the reason the earlier "#893 — shut down by the node" sentence was false. The drain itself is pinned where it lives: `WriteBehindTest#writeBehind_queueDrainOnShutdown` / `#writeThrough_shutdownIsNoop` (`integrations/storage`). [mechanism: reading of `StorageFactory` and `StorageInstance.storageInstance` overloads]
- The ordering (after the invoker, before the cluster node) is pinned by reading only; no test drives a write through a DHT tier during stop. [unverified: ordering under a live cluster stop]
