### Fixed (2026-11-12 — #2596: a consumer on a forwarding node never reached `Persisted`)
- **A forwarding node's cursor checkpoint was retried forever as `LocalOnly`** (#2596). The replica filter excludes `StreamCursorCheckpointKey`, so a forwarding node's committed-state mirror never shows a cursor the core admitted, and the read-back verdict reported `LocalOnly` after every attempt, each costing a `Put` and a `Noop` consensus command. When the node forwards, its replica excludes the key and the mirror shows no cursor, the verdict now comes from the committed assignment: still naming this node means `Persisted`, moved means `Fenced`. A mirror that does show a cursor keeps the read-back path. Not covered: the rewind fence (#1333), which `restartRewound` still handles.
