### Fixed (2026-10-18 — #2256: the `@Tag("S3")` tests never ran, locally or in CI)
- **`-Dgroups=S3` selected zero tests**: the root pom's `exclude-tagged-tests` profile set surefire's `excludedGroups` as a literal (`Infinite, Slow, Benchmark, S3`), which a `-DexcludedGroups=` on the command line cannot override, so the documented command ran S3 AND NOT S3. The exclusion is now the property `surefire.excludedGroups` (same default); `-Dgroups=S3 -Dsurefire.excludedGroups=` runs the group.
- **New workflow `.github/workflows/s3-tests.yml`** runs the S3 group of `integrations/storage` and `aether/node` against MinIO (Chainguard's build; MinIO's own images are no longer publicly pullable) on the same triggers as `ci.yml`, and fails when a module's group selects zero testcases.
