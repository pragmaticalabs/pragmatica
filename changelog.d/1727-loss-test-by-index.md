### Changed (2026-09-30 — #1727: the loss test checks delivery by write, not by count)
- `QuicLaneFinishUnderLossTest` now records which writes were acknowledged and requires each of those exact writes to reach the acceptor. Before, it compared the number of delivered writes with the number acknowledged, so a failed write that was delivered anyway could stand in for an acknowledged one that was lost. On failure it lists only acknowledged-but-undelivered writes (previously the expected post-finish failures were listed too).
