### Added (2026-10-18 — #2226: generated JSON codecs for slice payloads, replacing the Jackson path)
- **Reflection-free JSON codecs generated at compile time.** A new runtime module, `integrations/serialization/json` (core only), plus a shared generator, `integrations/serialization/json-codegen`. `@Json` on a record or enum generates a `<Type>Json` entry point. `JsonCodecs.codecFor(Class)` finds it through a per-type `ServiceLoader` provider. Codecs combine with `listOf`/`setOf`/`optionOf`/`mapOf`. A type the generator cannot handle fails the build and names the reason. `[verified: integrations/serialization/codec-processor/src/test/java/org/pragmatica/serialization/codec/CodecProcessorTest.java, integrations/serialization/json-tests/src/test/java/org/pragmatica/serialization/json/tests/JsonCodecsTest.java]`
- **Slice HTTP routes use generated codecs automatically.** The slice processor generates a codec for every route body type and response type it can handle; any other type gets a compiler note and stays on Jackson. A decode failure is a 400 that names the target type. `[verified: aether/http-routing-adapter/src/test/java/org/pragmatica/aether/http/adapter/SliceRouterGeneratedCodecTest.java, aether/http-routing-adapter/src/test/java/org/pragmatica/aether/http/adapter/SliceRouterJsonBodyTest.java]`
- **Standards-compliant parser.** The reader accepts all 95 `y_` cases and rejects all 188 `n_` cases of JSONTestSuite, and pins the `i_` cases. In benchmarks on ticketing and example payloads it decodes 1.6–8.0× and encodes 1.7–3.3× faster than Jackson, and allocates less. `[verified: integrations/serialization/json/src/test/java/org/pragmatica/serialization/json/spi/JsonTestSuiteTest.java]`
