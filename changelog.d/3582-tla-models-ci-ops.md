### Added (2026-11-23 — #3582, #3583, #3584: TLA+ models in CI, fragment-touched check, evidence rows)
- **The embedded TLA+ models run in CI**, one job per model (`tools/tla/plan-matrix.py`), on a push to the release branch that touches `tools/tla/**` or a Java file carrying a `tla` fragment, on a nightly schedule and on demand. Rows too slow for the small profile are marked `heavy`: the small profile records them as `SKIPPED-HEAVY` by name, never as a pass. `[verified: tools/tla/test_plan_matrix.py, tools/tla/runselftest.sh heavy-* cases]`
- **`TLA+ PR checks`**: `fragment-touched` fails a pull request that changes code under a `tla` fragment without changing the fragment (`tools/tla/touched.py`), `evidence-rows` checks the model-run rows a PR commits to `tools/tla/results.tsv` (`tools/tla/results-check.py`), and `fragment-paths` fails a PR whose `paths:` list of `tla-models.yml` is out of date, or whose model module has fragments but no `models.tsv` row. `[verified: tools/tla/test_touched.py, tools/tla/test_results_check.py, tools/tla/test_fragment_paths.py]`
- **The CI jar is one pinned asset**: the `tla2tools-2026.11.06` release of this repository, checked against its sha256 in every job (also on a cache hit); the README says how to move the pin. `[verified: tools/tla/test_workflow.py]`
