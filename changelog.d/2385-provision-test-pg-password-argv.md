### Security (2026-10-22 — #2385: provision-test-pg.sh exposed the database password in argv and `bash -x` traces)
- **`tools/provision-test-pg.sh` passed the PostgreSQL password as command arguments.** It sat in a shell variable and travelled through `jq --arg`, `curl -d` (the Hetzner create-server body), the smoke test's `ssh ... docker exec -e PGPASSWORD=...` and the VM's `docker run -e POSTGRES_PASSWORD=...`, so it was visible in `ps` on both machines and printed by `bash -x`. The password now lives only in a mode-0600 file in a private work directory that is removed on exit: the request body goes to `curl` on stdin, templates are filled from the file, the VM receives it in a root-only env file read by `docker run --env-file`, and the smoke test sends none (psql runs over the container's local socket). The env file the script writes is unchanged. [verified: `script-gate/src/test/java/org/pragmatica/scriptgate/ProvisionTestPgSecretTest.java`]
