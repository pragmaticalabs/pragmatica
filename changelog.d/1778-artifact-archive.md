### Added (2026-10-02 — #1778 / #1102: `DELETE /repository/{group}/{artifact}/{version}` archives a version; retention is configurable)
- **Archive instead of delete.** `ARTIFACT_DELETE` was declared and served by nobody (#1102). `DELETE /repository/{groupPath}/{artifactId}/{version}` now archives the version (OPERATOR or ADMIN, as a push): it writes an `archived` marker key and flags the version in the versions list, keeping every key, so "absent" still means "never written". An archived version answers `410 Gone` on `GET` (files and `.sha1`/`.md5` sidecars), is delisted from `maven-metadata.xml`, refuses new files and any `PUT` (`409`), and the built-in repository reports it as "not in store" so other repositories can still serve it. Nothing is archived before the version has been stored for the minimum retention period; a younger version answers `409`, a version never stored answers `404`, archiving twice is a no-op, and an interrupted archive completes on re-run. The retention default of **7 days is a guess recorded for the owner**, set with `[slice] artifact_archive_retention` (`"7d"`, `"36h"`, ...). Chunk bytes of archived versions are not reclaimed. `aether artifacts archive <group:artifact:version>` replaces `artifacts delete` (kept as an alias). `[verified: ArtifactStoreWriteOnceTest#Archive, #NeverResurrected, MavenProtocolHandlerWriteOnceTest, MavenProtocolRoutesArchiveTest, ArtifactArchiveCommandTest — archive marker ignored on resolve: 5 red; ignored on deploy: 4 red; retention check removed: 2 red; DELETE route unclaimed: 3 red; admission bypassed: 2 red]`
- **State order never-written < present < archived.** Reads obey the archive marker, a key of its own that any replica holding it wins ("present beats absent"), so a replica that missed the archive write, or a repair replaying an older list, cannot make an archived version resolve. `[verified: ArtifactStoreWriteOnceTest#NeverResurrected.resolve_staysArchived_whenOneReplicaMissedTheArchiveWrite (three replicas, read quorum two, the real QuorumCollector), .resolve_staysArchived_whenARepairReplaysAStaleVersionsList]` `[unverified: the versions-list archived FLAG, which only drives listing, can still be lost to the cross-node list race above; `aether artifacts archive` re-run restores it]`
- `[slice] artifact_archive_retention` is parsed and reaches the store policy through `RepositoryFactory.archivePolicy`. `[verified: ConfigLoaderTest (3 pins), RepositoryFactoryArchivePolicyTest — parse ignored: 2 red; seam ignores config: 1 red]` `[unverified: the one-line call site in AetherNode that passes `RepositoryFactory.archivePolicy(config.sliceConfig())` to the store is read, not pinned — a mutation there stays green]`
