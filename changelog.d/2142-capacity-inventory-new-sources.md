### Fixed (2026-10-18 — #2142: seed-to-operator config transition skipped source inventory)
- **Sources committed after the bootstrap seed were never inventoried before the capacity ledger admitted on them.** The ledger's `inventoryComplete` bit is set once, under the seed, when only the implicit local source exists; `ensureInventory` returned early on it forever, so an operator configuration naming a source with pre-existing labelled instances admitted provisioning without counting them, risking paid instances past the limit. `CapacityControlledLifecycle` now remembers which (source, cluster) pairs it has inventoried and, before admission, lists every committed source it has not, so the existing instances are observed into the ledger first. The set is instance-local: a new leader re-lists each source once, which cannot double count because observation skips reservations already observed. `[verified: aether/aether-deployment/src/test/java/org/pragmatica/aether/deployment/cluster/CapacityControlledLifecycleTest.java sourceCommittedAfterTheSeed_isInventoriedBeforeTheLedgerAdmitsOnIt]`
