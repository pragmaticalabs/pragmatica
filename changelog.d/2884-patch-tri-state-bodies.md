### Added (2026-11-08 — #2884: request bodies could not tell a left-out field from an explicit `null`)
- **A PUT-style partial update could not tell "leave this field" from "clear this field": both JSON paths read a missing member and `"field":null` as the same empty `Option`.** The new sealed `org.pragmatica.lang.Patch<T>` (`Absent | Null | Value`, factories `absent()`, `nullValue()`, `value(v)`, combinators `fold`, `map`, and `applyTo(Option)` for the update itself) keeps the three apart. `Option` is unchanged: a missing member and `null` both still read as empty, and an empty `Option` still follows the null-inclusion option [verified: `PatchParityTest.option_*`].
- **Both codec paths read and write it alike, as a record component:** a missing member is `Absent` and is left out on write, `null` is `Null` and is written as `null` (under either null-inclusion option), a value is a `Value`. The generated codecs (json-codegen) and the Jackson mapper (`PragmaticaModule`: `PatchSerializer`, `PatchDeserializer`, an as-property inclusion that leaves out `Absent`) agree byte for byte [verified: `PatchParityTest` (json-tests), both paths, all three states, round trips and cross-path decodes], and a real slice applies the update end to end through its generated router on the generated-codec body and on the Jackson fallback body [verified: `GeneratedRoutePatchTest` (slice-processor-tests)].
- **Anywhere else a `Patch` is refused, never misread:** as the whole body, a list or set element, a map value, or inside an `Option` or another `Patch` there is no "missing" state, so `@Json` fails the build, a slice route takes the Jackson fallback with a NOTE giving the reason, and Jackson refuses the type at its first read or write with the same reason; an `Absent` that a member's own `@JsonInclude` would write as `null` is refused too [verified: `CodecProcessorTest.JsonTests.json_failsCompilation_forPatch*`, `JsonCodecFallbackDiagnosticsTest.PatchOutsideARecordComponent`, `PatchParityTest.jackson_*`, `GeneratedRoutePatchTest.put_patchAsAListElement_isRefused`].
