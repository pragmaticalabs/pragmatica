### Removed (rc6 — TTM predictive scaling)
- **TTM is removed entirely** (owner ruling R-8). The modules `aether-ttm` and `aether-ttm-onnx`, `TTMManager`, `AdaptiveDecisionTree`, `TtmConfig`, the `[ttm]` TOML section, the `aether ttm status` / `aether ttm training-data` CLI commands and the `GET /api/v1/ttm/status` / `GET /api/v1/ttm/training-data` routes no longer exist. The feature was off by default, so no default behaviour changes; a `[ttm]` section in a config file is now ignored.
- The `ttm` slot is gone from `AetherConfig`, `AetherNodeConfig` (its staged builder goes from `cache` straight to `controllerConfig`) and `ManageableNode`; `MinuteAggregator.toTTMInput` is removed. `ttm-guide.md` and `contributors/ttm-integration.md` are deleted and the scaling docs now describe the reactive decision tree only. The BSL module list loses the two modules.
