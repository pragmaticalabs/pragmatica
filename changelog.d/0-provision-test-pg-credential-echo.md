### Security (2026-10-22 — provision-test-pg.sh printed the PostgreSQL password and credential-bearing URL to stdout)
- **`tools/provision-test-pg.sh` wrote `PG_PASSWORD` and the `PG_URL` that embeds it to stdout on every run.** The env file is mode 0600, but stdout lands in terminal scrollback, CI job logs and any wrapper that captures the output; the idempotent-reuse and `--print-only` paths, the ones run most often, did it too. No caller parsed stdout; every consumer sources the env file (`set -a; source /tmp/aether-test-pg.env; set +a`), which is unchanged. `[verified: script-gate/src/test/java/org/pragmatica/scriptgate/ProvisionTestPgOutputTest.java]`
