### Fixed (2026-09-19 — #1298: a fold in flight across a projection rebuild is applied twice)
- **A fold in flight when `Projection.rebuild()` ran wrote into the reset model under the OLD generation**, and the replay then applied the same event again (a counting fold read 2 for one event); on the single-argument path the late write carried state derived from the pre-rebuild model into the rebuilt one.

Because rebuild bumps before it resets, a late write is either cleared by the reset or refused, so the replay is the only writer of the rebuilt model. The guarded path fences on its claim's generation.
