### Changed (2026-10-19 — #2308: Promise.any reported "other Promise instance succeeded" when every input failed)
- **Behaviour change:** `Promise.any(Promise...)` and `Promise.any(List)` used to resolve with `CoreError.Cancelled("Cancelled because other Promise instance succeeded")` when every input failed, which was false and discarded the real causes. They now resolve with a `Causes.CompositeCause` holding the cause of every input, in input order (not completion order), the same shape `Promise.all` produces. Code that matched on the old `Cancelled` message or type for an all-failed `any` must read the composite instead. The overloads taking an explicit `failureResult` are unchanged, and inputs cancelled after a success still fail with `CoreError.Cancelled("Promise cancelled")`. `[verified: core/src/test/java/org/pragmatica/lang/PromiseAnyTest.java]`
- `any` over zero inputs still never resolves; this is now pinned by a test and stated in the javadoc.
