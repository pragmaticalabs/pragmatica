### Fixed (2026-10-02 — #1835: NODE_FAILED and the CRITICAL alert are only raised for a member this node observed reachable)
- **A configured core that never came up no longer produces `NODE_FAILED` plus a CRITICAL node-health alert.** `MembershipFsm` promotes configured cores to MEMBER at wiring time, before any packet moves, and every DEAD edge then fired the failed verdict, so a slow-booting JVM seed (150-200 s) or a phantom seed was reported as a failure although it never joined. The FSM now reads its `everReachable` latch (QUIC handshake, SWIM ALIVE, governor or worker-admission health; SWIM ALIVE includes gossip-relayed ALIVE, so the evidence is not necessarily first-hand) AT the DEAD edge, under the member's monitor, and fires exactly one of two new listeners: `onReachableDeath` (wired to `NodeDepartureNotifier`, which still owns the event and alert pair) or `onNeverReachableDeath`. [verified: `MembershipFsmTest.ReachabilitySplit`, `NodeDepartureNotifierTest`, `NodeDepartureWiringTest`]
- **A never-reachable death is reported as a WARNING `OPERATOR_WARNING` event with code `node-never-joined`**, so the operator still sees a configured core that never came up. No new wire type or enum constant: it reuses the #1574 event and adds one catalogue code.
- **Unchanged:** `onMembershipDeath` (auto-heal, dropping the peer's link, quorum nudge, leader reconciler) still runs for EVERY DEAD edge. The #926 contract holds with one narrowing: both surfaces are emitted, with no leader gate, on every observer that confirms the death of a member it had seen reachable. [verified: `MembershipFsmTest.ReachabilitySplit.confirmedDeparture_stillFiresForNeverReachableDeath`, `NodeDepartureWiringTest.membershipDeath_staysUnconditional_andCarriesNothingElse`]
- [unverified: the verdict is per observer. A node that boots after the peer was already up and dies before this node ever sees evidence for it reports `node-never-joined`, not `NODE_FAILED`, from this observer.]
- Out of scope, rc5 follow-up: seeds are still treated as members before they are reached, and the #1834 75 s cold-boot window is still a time knob rather than an identity gate.
