### Fixed (2026-10-18 — a SINGLE-mode scheduled task no longer runs twice when leadership changes mid-fire, #1155)
- **Before:** the in-flight guard of a scheduled task was a set inside each node's scheduler. A leader elected while the previous leader's fire was still running started with an empty set and fired on its next tick, so one schedule ran twice; the old leader also wrote the task row when its run ended, as a non-leader.
- **Now:** a SINGLE-mode fire is claimed in cluster state before it runs (`ScheduledTaskClaimKey`/`ScheduledTaskClaimValue`, tags 2163/2164, recorded in the wire baseline) and the claim is given up when it settles. A leader that finds a held claim does not fire; the tick is a recorded skipped overlap. The claim row is `VersionFenced`: the applier takes a write only as the immediate successor of the committed row. A claim older than `max(interval, completionBound + max(1 s, completionBound / 10))` (11 minutes with the default 10-minute bound) is taken over by the next leader; the old run's release is then refused by the applier and its outcome is not recorded, so one run is recorded per claim.
- **Guarantee, and what it is not:** at most one run is STARTED per claim while its holder is alive, and at most one run's outcome is recorded. A run that is overridden has already executed (the invocation cannot be cancelled), so after a leader is lost mid-fire the callee can run twice, once recorded. A leader lost mid-fire also costs its task up to the bound above. Claim time is the claimant's wall clock read against the evaluator's, so clock skew moves the bound by the skew. `/inject` still takes no cluster claim and can overlap a running fire.
- **Cost:** SINGLE-mode only. One claim row per task (removed with the task, not per fire) and two extra writes per fire (claim and release) next to the one state-row write. ALL-mode is unchanged. A claim write that cannot be committed skips the tick.
- Mechanism: `ScheduledTaskClaims`, `ScheduledClaimStore` (`aether-invoke`); `AetherNode` wires the committed store.
