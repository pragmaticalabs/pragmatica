### Fixed (2026-10-18 — #2262: path and query parameters dropped on byte[] routes)
- **A slice route consuming a binary type (`byte[]` parameter) silently dropped its declared path and query parameters**: `PUT /files/{id}` compiled, and the generated route parsed `id` and discarded it. The slice processor now refuses at compile time a binary or multipart route that declares path or query parameters, and the message says why. Multipart routes were already refused, with a message about record components. [verified: jbct/slice-processor/src/test/java/org/pragmatica/jbct/slice/SliceProcessorTest.java]
