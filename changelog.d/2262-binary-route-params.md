### Fixed (2026-10-18 — #2262: path and query parameters silently dropped on body routes)
- **A slice route whose body cannot carry its declared path and query parameters dropped them silently.** This covered `byte[]`, `String` (text/html/xml), `MultipartRequest`, and JSON bodies that are not records. For example, `PUT /files/{id}` compiled, and the generated route parsed `id` and discarded it. The slice processor now refuses any such route at compile time with one clear error. Only a JSON request record, which merges the parameters into its components, may declare them. The misleading "add a record component" error that followed the multipart refusal is gone. [verified: jbct/slice-processor/src/test/java/org/pragmatica/jbct/slice/SliceProcessorTest.java, MediaTypeTypeCheckerTest]
