### Added (2026-10-23 — #1779: map jsonb/json columns to typed records in the async Postgres path)
- **`@Jsonb` maps a `json`/`jsonb` column to a record.** Put it on a row-record component, a `@Query` method (its single result column) or a parameter. The generated factory encodes and decodes the document with a codec generated at compile time by the same generator the slice router uses for HTTP bodies. It uses no reflection and no Jackson, and its defaults are fixed: deploy-time JSON settings never change stored documents. The holder is `<Interface>JsonCodecs`, beside the factory. `[verified: aether/pg-tools/pg-codegen/src/test/java/org/pragmatica/aether/pg/codegen/processor/JsonbPostgresRoundTripTest.java, aether/pg-tools/pg-codegen/src/test/java/org/pragmatica/aether/pg/codegen/processor/JsonbMappingTest.java]`
- **`JsonText` binds to `json` and `jsonb` alike.** The async connectors register one text converter. A `JsonText` parameter has no declared type, so the server types it from the column or operator (`@>`). A `String` parameter is declared `varchar`: a `jsonb` column refuses it when the statement is prepared fresh, but accepts it when the connection reuses a statement prepared earlier for the same SQL with an untyped parameter, so neither outcome can be relied on. `[verified: aether/resource/db-async/src/test/java/org/pragmatica/aether/resource/db/async/JsonTextConverterTest.java, JsonbPostgresRoundTripTest.java]`
- **Nullable columns as `Option<T>`.** An `Option<T>` row component reads SQL `NULL` as empty through the new `RowAccessor.getOptional`. Before, such a component was a compile error. An `Option<T>` parameter binds empty as `NULL`. `T` is a column type, a value object or a `@Jsonb` document. `[verified: JsonbMappingTest.java, JsonbPostgresRoundTripTest.java, aether/slice-testkit/src/test/java/org/pragmatica/aether/testkit/fake/MapRowAccessorTest.java]`
- **Compile-time checks.** A `@Jsonb` type the codec generator cannot handle fails the build with the generator's reason. The escape hatch is a hand-written `ValueMapping<T, JsonText>`. A `@Jsonb` target whose known column (CRUD table, `WHERE column = :param`) is not `json`/`jsonb` also fails the build. `[verified: JsonbMappingTest.java]`
