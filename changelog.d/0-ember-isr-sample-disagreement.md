### Fixed (2026-10-10 — Ember failover test scored a disagreeing ISR sample as an ISR of size 0)
- **`EmberOrdinaryFailoverNoFalseAlertTest` could fail on any PR.** Its sampling loop folded a sample taken while the live nodes disagreed on the committed record (for example mid-transition, v4 on one node and v5 on another) into the minimum as an ISR of size 0, so the "kept every live member" assertion read 0 where the ISR never shrank. A disagreeing sample is now skipped, and the test asserts that at least one agreeing sample was taken after the first acknowledged publish, so it cannot pass on zero samples. No assertion threshold changed. [verified: `MinimumLiveIsrTest`; restoring `.or(0L)` turns all three of its cases red]
