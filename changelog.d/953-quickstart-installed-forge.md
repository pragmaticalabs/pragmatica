### Fixed (2026-10-14 — #953: the README Quick Start could not work on a clean machine)
- **The Quick Start never cloned the repository, and every example built Forge from source.** The README ran the installer and then `cd examples/pricing-engine`, a directory nothing had created; the installed Forge was never used, because each `examples/*/run-forge.sh` hardcoded `aether/forge/forge-core/target/aether-forge.jar` and built it, and the example, with `-pl … -am` from the monorepo root.
- The Quick Start is now install, clone, `cd`, start PostgreSQL, `./run-forge.sh`, and `curl` in a second terminal. It names its release once, `AETHER_VERSION=<V>`: the installer installs that release (`--version`) and the clone takes tag `v<V>`, so the tools and the examples cannot drift apart. The six `run-forge.sh` scripts share `examples/run-forge-lib.sh`, which uses `$AETHER_FORGE`, then `aether-forge` on `PATH`, then the installer's `~/.aether/bin/aether-forge` and `~/.aether/lib/aether-forge.jar`, and otherwise fails with the install command. A Forge built from the checkout is the contributor path, taken only with `--forge-from-source`. Each example now builds from its own `pom.xml`, against published artifacts only. [verified: `tools/quickstart-check.sh` against `1.0.0-rc4-candidate`]
- **New gate, `tools/quickstart-check.sh`.** It extracts the Quick Start blocks from `README.md` and runs them in a clean container (no `~/.m2`, no checkout) with a private Docker daemon for PostgreSQL. It fails unless the README's `AETHER_VERSION` equals the version of the tree under test (the root pom's, minus `-SNAPSHOT`), and it accepts the second terminal only when its output carries a numeric `totalPrice`. `--version` runs the Quick Start against a candidate, and a Maven repository can stand in for Central until the version is published there; `stage-repo` builds that repository from the publish set. Deleting the README's clone step, a wrong path in the `curl`, or a stale `AETHER_VERSION` turns it red. [verified: `tools/quickstart-check.sh`]
- **Release step: bump the Quick Start version.** When the root pom moves to a new version (the "update README.md version references" step of preparing a release branch), set `AETHER_VERSION` in the README Quick Start to it as well; `tools/quickstart-check.sh` fails on a mismatch, naming both versions.
- `aether/README.md`, the slice-developer getting-started guide, the Forge guide and the deployment guide now say that Forge comes from the installer, and label the source build as the contributor path.
