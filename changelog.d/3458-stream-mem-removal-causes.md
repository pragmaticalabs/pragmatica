### Changed (2026-11-21 — #3458: a refused cursor names the SET of removal causes behind the range)
- **`ReadRefusal` gained an `int causes` component after `cause` (one bit per `RemovalCause` ordinal), and `StreamError.CursorExpired` gained `Set<RemovalCause> causes`; the type and the wire move together.** The wire generation is bumped to 10: the join guard refuses a node of the new generation joining beside handshaken members of an older one, because they cannot decode the extra component.
- Every constructor that predates `causes` derives it: a form that names a cause gives `{cause}`, and `UNRECORDED` gives the empty set. Only `CURSOR_EXPIRED` carries a set; decoding never throws (a bit at or above `UNKNOWN`'s ordinal reads back as `UNKNOWN`, the `NOT_APPLICABLE` bit is dropped). Nothing produces a set beyond that default yet.
