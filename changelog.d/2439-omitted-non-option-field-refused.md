### Changed (2026-10-27 — #2439: Heavy nightly reds after the generated JSON codecs and the observer lag warning)
- **A slice HTTP request body that omits a non-`Option` record component is now refused with 400, whatever the component's type.** Since the generated codecs (#2226/#2229) every record component that is not `Option<T>` is required: an omitted boxed `Long`/`Integer` or `String` used to arrive `null` under Jackson and is now `Invalid JSON body for <Type>: Missing required field: <name>`. A slice author who means a field to be optional declares it `Option<T>`; an omitted `Option` component decodes as `none()`. The codec is not relaxed (JBCT: absence is `Option`). `[verified: aether/http-routing-adapter/src/test/java/org/pragmatica/aether/http/adapter/SliceRouterGeneratedCodecTest.java]`
- The `test-entity` blueprint's `TimerRequest` now declares `Option<Long> delayMillis` and `Option<String> token`, so the timer gates that omit them pass again. `[verified: aether/forge/forge-tests/src/test/java/org/pragmatica/aether/forge/DurableEntityForgeTest.java, aether/forge/forge-tests/src/test/java/org/pragmatica/aether/forge/DurableEntityTimerDurabilityTest.java]`
