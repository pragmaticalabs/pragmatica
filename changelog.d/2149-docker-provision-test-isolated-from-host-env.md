### Fixed (2026-10-18 — #2149: DockerProvisionViaIdentityTest failed when the environment exports AETHER_CLUSTER_SECRET / AETHER_API_KEY)
- **A developer machine that exports the cluster secret or API key failed three tests before any assertion ran.** The test built its provider with the two-argument `dockerComputeProvider(runner, config)`, which reads the real process environment, so provisioning refused on the node's own variables (#1650). The test now injects an empty host environment through the three-argument factory. `DockerComputeProvider`'s cluster-name fallback (`AETHER_CLUSTER_NAME`) read the real process environment even when a host environment was injected; it now reads the injected one, like every other host read in the provider. `[verified: aether/environment/docker/src/test/java/org/pragmatica/aether/environment/docker/DockerProvisionViaIdentityTest.java, whole module green with the secret, API key and cluster name exported; two new tests pin that the cluster-name fallback is injected]`
