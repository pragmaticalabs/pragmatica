### Changed (2026-11-12 — #3089: `-Daether.requireDocker=true` turns a missing Docker daemon into a failure for every Docker-backed test)
- **One shared guard, `org.pragmatica.testing.DockerRequirement` (plus `@RequiresDocker` for whole classes), replaces the 28 per-file Docker checks and the five per-module `DockerRequirement` copies (#2591).** Without `aether.requireDocker` a missing daemon still skips (#466); with `-Daether.requireDocker=true` the guard throws an error naming the property, so a class-level `assumeTrue` can no longer end as a report with `tests="0" skipped="0"`. `@Testcontainers(disabledWithoutDocker = true)` is replaced by `@RequiresDocker` + `@Testcontainers`. `-Daether.hideDocker=true` stays as the test-the-guard switch.
- **CI:** unchanged switch (#2591): the test-group job and the Docker-hidden control step pass `-Daether.requireDocker=true`.
