### Changed (2026-11-12 — #3089: `CI_REQUIRE_DOCKER=1` turns a missing Docker daemon into a failure for every Docker-backed test)
- **One shared guard, `org.pragmatica.testing.DockerRequirement` (plus `@RequiresDocker` for whole classes), replaces the 28 per-file Docker checks.** Without `CI_REQUIRE_DOCKER` a missing daemon still skips (#466); with `CI_REQUIRE_DOCKER=1` (or `true`) the guard throws an error naming the variable, so a class-level `assumeTrue` can no longer end as a report with `tests="0" skipped="0"`. `@Testcontainers(disabledWithoutDocker = true)` is replaced by `@RequiresDocker` + `@Testcontainers`. The five per-module `DockerRequirement` copies (#2591) and the `-Daether.requireDocker` property are gone; `-Daether.hideDocker=true` stays as the test-the-guard switch.
- **CI:** the test-group job and the Docker-hidden control step set `CI_REQUIRE_DOCKER=1`.
- **Guard against bypass:** `DockerGuardBypassTest` (module `testing`) fails the build when any `.java` file outside the helper uses `isDockerAvailable` or `disabledWithoutDocker`.
