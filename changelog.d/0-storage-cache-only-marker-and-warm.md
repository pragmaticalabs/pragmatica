### Added
- A storage instance records a block it only read from the cluster-shared tier as a cache-only marker, so its accesses are counted and any copy it keeps is visible to demotion; garbage collection never collects a marker, demotion evicts a cached copy instead of moving it down, and promotion caches it in the nearest non-durable tier instead of on the durable disk. Markers are bounded: past a cap, idle markers that track nothing local are swept. The metadata snapshot format gains an optional trailing `CACHE_ONLY` field written only for a marker, so snapshots written before it restore unchanged.
- `StorageInstance.warm(id)` copies a block into the instance's cache tiers when no node-private tier holds it (`exists` on the shared tier never fetches), and a storage instance can be given a listener told of every read hit.
### Fixed
- The cache-only marker bound is hard: warmed and snapshot-restored markers are counted, and `warm` records a marker only after a cache tier accepted the copy. A failed required write over a warmed block keeps the cache copy tracked instead of leaving it untracked. `exists` is true only for a block that is readable (a marker whose shared copy is gone is not), and `createRef` over a marker is refused with a typed error.
