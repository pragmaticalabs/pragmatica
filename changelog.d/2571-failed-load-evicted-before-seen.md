### Fixed (2026-11-02 — #2571: SliceStoreConfigWatchLifecycleTest flakes on "no half entry is left in the map")
- **A failed slice load could still be cached when its caller saw the failure.** `SliceStore.loadSlice` evicted a failed load's entry in an independent `onFailure` action. That action runs asynchronously, so the caller's own continuation could run first, and a retry right after the failure got the cached failed load back. The eviction is now a dependent step: the failure is visible only after the entry has left the map.
