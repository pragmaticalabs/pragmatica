### Fixed (2026-11-24 — #3661: a temp file vanishing during a directory walk failed the whole listing)
- **`FileOps.walk` skips entries that vanish while it runs** (#3661). A concurrent atomic write (`0.acked.tmp`, then rename) can remove an entry between the walk's directory read and its attribute read; `Files.walk` then threw and the whole listing failed, so the stream WAL listing logged "orphaned lives are not checked" for that boot. The walk now lists every other entry; an unreadable directory or a missing walk root still fails it. `FileOps.list` already did not stat entries and is unchanged.
