### Fixed (2026-11-05 — #2132: replace-before-retire drained a literal `<source>-<role>-old-N` host, never the node it retires)
- **A source-field change now drains the real old node** (#2132). `cluster apply` replaces the nodes of a source whose field changed by creating the replacements first and then draining the old nodes, but it addressed the old node by the literal `<source>-<role>-old-N`, as both its id and its host, so the drain never reached a node. The old nodes are now discovered from the provider by the cluster, source and role labels (docker `aether.*`, cloud `aether-*`; an SSH source's configured hosts), the replacements this run just created are excluded, and each is drained by the id it registered under at the address the provider reports for it, waiting for the drain to complete. Fewer old nodes than the plan names, or one with no address, is refused with a typed cause before any drain.
