### Added (2026-10-25 — core side of the worker replica feed: serve and wire)
- **Cores serve the replica feed.** A core with a committed cluster incarnation now records the commit ring (the production `ClusterIncarnationKey` reader is wired into the store) and answers `ReplicaSubscribe` with the ring's entries and a one-second heartbeat, and `ReplicaSnapshotRequest` with the filtered snapshot in 64 KiB chunks. Snapshot capture and serve run on a dedicated serve pool, never on a network thread; at most two snapshot transfers run at once and a further asker is answered `BUSY`; subscriber queues, the snapshot cache and the subscription count are bounded. No worker subscribes yet, so a running cluster behaves as before apart from the extra ring and heartbeat work on cores. [verified: integrations/cluster/src/test/java/org/pragmatica/cluster/replica/ReplicaFeedServerTest.java, aether/node/src/test/java/org/pragmatica/aether/node/ReplicaIncarnationSourceTest.java]
- **A cluster directory rides the ClusterSync ping and pong.** The leader's authority ping carries the node list and the DHT replication to cores and governors until each reports the current version; every node caches the directory and reports the version it holds on every ping, and answers a ping with its own directory only when strictly newer than the asker's. Nothing reads it on a worker yet. [verified: aether/aether-metrics/src/test/java/org/pragmatica/aether/metrics/ClusterSyncDirectoryTest.java, aether/aether-metrics/src/test/java/org/pragmatica/aether/metrics/ClusterSyncLeaderDirectoryTest.java]

### Changed (2026-10-25 — core side of the worker replica feed: serve and wire)
- **Stop-the-cluster upgrade across this build.** `ClusterSyncPing` and `ClusterSyncPong` gain two components at the end, so a rolling upgrade breaks: an old node drops the tail of a new message and a new node fails to read an old one, pings and pongs are lost, and the leader emits ping-timeout hints for live nodes. Stop every node and start them all on the new build. Pre-GA: no migration path is provided.
