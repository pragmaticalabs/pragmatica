### Removed (2026-09-04 — #854: dead `[operations.tls] cluster_secret` bootstrap key)
- **`TlsDeploymentConfig.clusterSecret()` had no live caller** — #824 deleted `DockerComposeGenerator`, its only reader, leaving the accessor unreachable and failing the dead-surface gate. The `cluster_secret` component is removed from `TlsDeploymentConfig`, the `[operations.tls] cluster_secret` TOML key is no longer parsed by `ClusterBootstrapConfigParser`, and the reference docs table drops the row [mechanism: `ConfigKeyLivenessTest.clusterBootstrapConfig_everyAccessor_isReachableExemptOrSuppressed` reflectively scans every config accessor for a live caller, reflective-binding exemption, or `@ConfigKeyLive` suppression].
- **This is unrelated to the live, same-named `cluster_secret`** used for cluster transport trust (`[tls] cluster_secret` / `AETHER_CLUSTER_SECRET`, read by `Main.resolveClusterSecret(TlsConfig)`) and to the CLI's own `BootstrapState.clusterSecret()` bootstrap-anchor field — neither is touched by this change.
- **An `[operations.tls] cluster_secret` line in an existing `aether.toml` is now silently ignored** rather than read into a dead field — `TomlDocument` has no unknown-key rejection anywhere in this parser, so this matches how every other unrecognized key in the file already behaves.
