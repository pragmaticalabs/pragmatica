### Fixed (#1404: unfinished cluster lifecycle work must survive lost events and leadership changes)
- Core replacement accounting includes committed non-installed allocations. Expiring a local replacement observation no longer authorizes another create while the original allocation remains uncertain; diagnostics identify `AWAITING_DURABLE_CAPACITY`. Admission backpressure defers without tripping the provider-failure circuit.
- Provider retirement records `RETIRING` before deletion. Periodic core cleanup retries after transient provider failures under the same leader, retaining current retirement safety checks. Automatic departed-core deletion respects disabled auto-heal (#1038).
- Continuing source inventory confirms missing observed allocations and releases their capacity. Uncertain creates remain reserved and cannot be released through an empty deletion confirmation. Configuration changes invalidate initial inventory completion for admission.
- Production implicit worker topology uses the community operation lifecycle, with targets derived from committed topology counts. Community and inventory passes isolate failures in bounded lanes; a stalled item delays later items in its lane by at most the observation deadline, and provider create admission is bounded per source binding. Delayed readiness can resume without replacing its reserved identity, and a positive target can reopen a dissolved community.
- The specification records provider uncertainty and physical-scale limits; these changes do not claim 10K-node/WAN validation or close the scale gates #367/#368/#599.
- Definitive provider refusals persist no-create evidence before contended accounting cleanup. Controller restart and release conflicts cannot turn that evidence into an unknown create. Confirmed provider absence removes stale worker placement in the same transaction as capacity release.
- Delayed readiness retains the old worker’s allocation exclusion; delayed evacuation escalates and resumes only with retirement proof. Binding outages retain the interrupted operation phase for safe resumption when the recorded source is restored.
