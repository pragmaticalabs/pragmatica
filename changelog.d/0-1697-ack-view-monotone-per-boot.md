### Fixed (2026-11-12 — #1697: a restarted replica holding less could never lower the owner's replicated view)
- **The owner's per-replica ack view is now monotone only within one replica boot.** `ReplicateAck` carries the replica's boot token; within one owner epoch the registry keeps the max for acks of the same boot (and for token-less owner-side evidence), and replaces the row, a lower value included, when a different boot token arrives. A same-NodeId restart that holds less no longer leaves the view over-counting.
