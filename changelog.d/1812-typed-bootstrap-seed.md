### Fixed (2026-10-03 — #1812: a seed-only cluster could not provision: the blank bootstrap config failed an unguarded parse)
- **Every cluster that had only its self-bootstrap seed (no `aether cluster apply` yet: Forge, self-bootstrapped clusters) refused all provisioning.** The seed stored `tomlContent = ""`; readers told it apart from a real config ad hoc, some with `isBlank()` and others not at all. The bound-source provisioning path added by #1390 (source binding, fleet inventory, bound resolution) parsed the blank seed, failed with "Persisted config has no config_version", and tripped the provisioning breaker. Auto-heal replacement and `/api/v1/cluster/scale` growth were dead on those clusters. [mechanism: the seed is a typed `none`, so the bound-source path resolves it to the explicitly local provider instead of parsing it; unit-pinned by `BootstrapSeedProvisioningTest`, which composes the real lifecycle → registry chain with a fake provider]
- `ClusterConfigValue.tomlContent` is now `Option<String>`: `none` is the seed (`ClusterConfigValue.bootstrapSeed`), `some` is a committed TOML. Every reader decides what the seed means at the type, and the `isBlank()` guards are gone. With no committed sources, only the explicitly local provider is provisionable, and only as the `default` source, under its own stable binding. The seed's fleet inventory lists that one source. [mechanism: no reader can reach the TOML string without folding over the seed case]
- The HTTP `GET` cluster-config response still renders the seed as `"tomlContent": ""`, which the CLI already reports as "no stored config".
- **Wire break (pre-GA, unsupported):** the KV encoding of `ClusterConfigValue` changed (`tomlContent` is now an `Option`). Decoding bytes written by an earlier build, including the cluster config inside a pre-#1863 backup and the value sent by a mixed-version peer, throws `ClassCastException` (`String` cannot be cast to `Option`) rather than a typed decode failure. There is no migration: wipe and recreate the cluster, and do not restore an older backup. [mechanism: the generated decoder casts the first component to `Option<String>`; measured in the #1863 verification]
