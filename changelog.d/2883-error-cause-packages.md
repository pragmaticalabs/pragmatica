### Added
- `routes.toml` `[errors] packages = ["com.acme.shared.errors"]` (#2883): the slice processor scans these packages for `Cause` types besides the slice's own package, so a shared error maps to its declared status instead of the default 500. Opt-in: a slice without the key behaves as before. A listed package that does not exist fails the build, naming it. Two listed packages that each declare a `Cause` of the same simple name stay apart: each is matched by its fully-qualified name (use a qualified reference such as `OneError.Denied` in the status lists) and the generated error mapper cases on the qualified type; an `[errors.explicit]` key may be a simple name or a fully-qualified name (`"shared.one.OneError.Denied" = 404`); a simple-name key that matches more than one discovered `Cause` type fails the build, naming every match and asking for the fully-qualified name, so one declared status never silently applies to unrelated errors. `routes-base.toml` and the slice's `routes.toml` lists are unioned.
