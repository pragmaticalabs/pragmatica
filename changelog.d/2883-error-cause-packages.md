### Added
- `routes.toml` `[errors] packages = ["com.acme.shared.errors"]` (#2883): the slice processor scans these packages for `Cause` types besides the slice's own package, so a shared error maps to its declared status instead of the default 500. Opt-in: a slice without the key behaves as before. A listed package that does not exist fails the build, naming it. Two listed packages that each declare a `Cause` of the same simple name stay apart: each is matched by its fully-qualified name (use a qualified reference such as `OneError.Denied` in the status lists) and the generated error mapper cases on the qualified type; an `[errors.explicit]` entry is keyed by simple name and applies to both. `routes-base.toml` and the slice's `routes.toml` lists are unioned.
