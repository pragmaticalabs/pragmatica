### Fixed (2026-11-24 — #3550: forwarded management request with an unknown HTTP method)
- **An unknown HTTP method on a forwarded management request threw out of the receiving node** (#3550). `ForwardedRequestContext` built its method with `HttpMethod.valueOf`, which throws before the secured path's unsupported-method guard could run, so the forwarding node got no reply. The context is now built from `HttpMethod.fromString` and is absent for an unknown method; the receiver answers with the typed `Unsupported HTTP method: <m>` error reply before validation and dispatch, as the local path does. [verified: `ManagementServerSecurityCouplingTest#forwardedPath_unsupportedMethod_returnsBeforeValidationAndDispatch`, `ForwardedRequestContextTrailersTest`]
