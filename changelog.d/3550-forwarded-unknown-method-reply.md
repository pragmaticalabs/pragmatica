### Fixed (2026-11-24 — #3550: forwarded management request with an unknown HTTP method)
- **An unknown HTTP method on a forwarded management request threw out of the receiving node** (#3550). `ForwardedRequestContext` built its method with `HttpMethod.valueOf`, which throws before the secured path's unsupported-method guard could run, so the forwarding node got no reply. The context is now built from `HttpMethod.fromString` and is absent for an unknown method; the receiving node now answers the forwarding node with a plain-text `success=false` error reply (`Unsupported HTTP method: <m>`) instead of throwing, before validation and dispatch; the client still gets 503, sooner (no hop timeout). [verified: `ManagementServerSecurityCouplingTest#forwardedPath_unsupportedMethod_returnsBeforeValidationAndDispatch`, `ForwardedRequestContextTrailersTest`]
