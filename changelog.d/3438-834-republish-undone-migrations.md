### Fixed (2026-11-20 — #834: a blueprint republish no longer reapplies schema migrations an operator undid)
- **A republish that would reapply undone schema migrations is refused unless forced** (#834). `SchemaVersionValue` now records how its version was reached (`reachedBy`: migrated, undone, baselined, unknown); a republish over an undone or baselined version is refused unless the publish request carries `force` (CLI `--force`, absent = false). Wire: the new shape takes tag 2984 and the reach enum 2985; tag 1638 stays the old shape and decodes as `reachedBy = MIGRATED` (decode-only, `LegacySchemaVersionValue`), so a snapshot written by an older build still restores.
