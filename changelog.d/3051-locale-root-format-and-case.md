### Fixed (2026-11-24 — #3051: wire, file and parsed-log output no longer depends on the default locale)
- **Wire, file and parsed-log output no longer depends on the default locale** (#3051, follow-up of #2974). Under `-Duser.language=de` a `%.2f` in a simulator/metrics JSON body printed `0,50`; under `ar` a `%d` in a deployment manifest port, a snapshot file name or the `file:line:col` lint location printed Arabic-Indic digits; under `tr` a bare `toLowerCase()` turned `I` into a dotless `ı`. Every such call outside `core` now uses `Locale.ROOT` (deployment manifests, snapshot file names, forge simulator and metrics JSON, jbct JSON reports and `Diagnostic` locations, schema marker, event durations, interceptor log line, docs samples). `LocaleIndependenceGateTest` (script-gate) scans the sources so a new bare format or case call fails the build unless its file is classified human-only.
