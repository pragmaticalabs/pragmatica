### Fixed (2026-11-10 — #2983: Forge runs app-http in JWT mode)
- **Forge passes `[app-http]` `security_mode = "jwt"` and its JWT config to its nodes** (#2983). `EmberCluster` dropped the JWT config (every node logged that `jwks_url` was missing and refused each non-public route with 401), and `ForgeServer.applyAppHttpSecurity` applied `[app-http]` only when API keys were declared. Forge now applies the section when a key is declared or the mode is `jwt`, and hands the nodes the JWT config (HS256 secret from `AETHER_JWT_SECRET`, or JWKS, plus `auth_schemes`, issuer, audience) through the new `EmberCluster.withAppHttpSecurity(mode, keys, jwtConfig)`. API-key behaviour is unchanged. `forge-guide.md` now documents the sibling `aether.toml` security settings, including JWT mode and the management plane under it.
