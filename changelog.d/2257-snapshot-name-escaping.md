### Fixed (2026-10-18 — #2257: storage metadata snapshot does not escape ref names)
- **A content or consumer-group name containing `=`, `|`, a newline or a leading `#`, or an empty name, made the snapshot it landed in unrestorable** (or silently dropped the name), and once every retained snapshot held such a name the node refused to boot. The streams instance snapshots on every seal, so the retained files turned over within minutes.
- Snapshots are now written as `format=2`: ref names are percent-encoded (UTF-8 bytes as `%XX`, a lone surrogate as `%uXXXX`), so every name round-trips, including the empty one. The integrity hash covers the epoch, every lifecycle line and every ref line (name and target) exactly as written, with delimiters.
- A snapshot is parsed back through the restore path before its file is committed, and the decoded result is compared by value with the in-memory snapshot (epoch, node id, every ref name and target, every lifecycle); one that does not read back equal is refused at write time with an ERROR log, and the previous snapshot and `LATEST` stay in place. Name encoding and validation are linear scans, so a name of any length (tested to 16 MiB) costs no stack.
- Files written before this change (no `format` header) are still restored and verified under the old hash, so an existing node is not bricked; new writes are always `format=2`. The old layout keeps its limits: a name with `=`, `|`, a newline or a leading `#` makes its file unrestorable (restore falls back to the next retained file), and an empty name is dropped silently without failing the hash, so the first `format=2` write after upgrade makes that loss permanent.
- **No rollback to a build without this change after the first `format=2` snapshot.** An older binary reads the `format=2` header but its hash differs, so it refuses the file (`NothingRestorable`); for the streams instance that happens within minutes of the first v2 write. To go back an operator must restore the snapshot directory from a copy taken before the upgrade, or empty it and accept a start with empty metadata. Accepted pre-GA: rc4 to rc5 is a fresh cluster, so only rc5 development builds are affected. `[verified: integrations/storage SnapshotNameEscapingTest, SnapshotNameCodecTest]`
