### Fixed (2026-10-18 — #2191: 09-artifacts large-artifact curl has no timeout and no transport retry)
- **One brief link interruption between the operator host and the cluster turned the 09-artifacts suite red against a healthy cluster.** `test-large-artifact.sh` pushed and resolved with bare `curl -s`: no `--connect-timeout`, no `--max-time`, no retry. Both calls now go through `curl_http_status`, which bounds each attempt, retries (3 attempts) only when curl itself failed (nonzero exit, a lost link), returns any HTTP answer at once so a 4xx/5xx is never retried, and logs curl's exit code on every transport failure. That a re-PUT of identical bytes answers 2xx is design intent, not yet run against a cluster. `[verified: aether/tests/integration/test/test-large-artifact-retry.sh]`
