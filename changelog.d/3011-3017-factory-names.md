### Changed (2026-11-11 — #3011, #3017: static factories are named `TypeName.typeName(...)`; `ValueMapping` moves to core)
- **`ValueMapping` moved from `org.pragmatica.aether.slice.mapping` (slice-api) to `org.pragmatica.lang.vo` (core)**, and `ValueMapping.of(lower, lift)` is now `ValueMapping.valueMapping(lower, lift)`. A value object that declares `valueMapping()` needs core only. Breaking (pre-GA, no alias): change the import and the call.
- **Every static `of(...)` factory in `*/src/main/java` is renamed after its type**, e.g. `Topic.topic(...)`, `Projection.projection(topic)` (a builder entry point, named like any other factory), `VisibleBounds.visibleBounds`, `SourceSpan.sourceSpan`, `CstNavigator.cstNavigator`, `SASLResponse.saslResponse`, `RuleKind.ruleKind`, the `jbct-derive` result types, `RouteSource.routeSource`, `NodeReplacementAnnouncements.nodeReplacementAnnouncements` and `UpgradeRunAnnouncements.upgradeRunAnnouncements`. Call sites, generated-code fixtures and javadoc follow.
- **`JBCT-NAM-01` flags a static method named `of` in every type kind** (class, interface, enum, record), whatever it returns. It previously reached only records returning themselves, so none of the sites above were reported. [verified: `CstFactoryNamingOfRuleTest`]
