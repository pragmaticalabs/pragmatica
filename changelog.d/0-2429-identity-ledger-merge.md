### Fixed
- A core whose identity ledger file was lost no longer stays isolated (#2429). The QUIC Hello now carries the retirements the sender can vouch for (a ledger that is loaded and not wiped); the receiving core unions them into its own ledger, forces it to disk, and only then admits the sender, so a wiped core regains what it lost on the first handshake with a core that remembers. A wiped core still admits no new peer before that merge; an offer with no retirement in it is no evidence and does not end the wiped state (a process for a retired NodeId looks exactly like that), and two wiped cores cannot end each other's wiped state. The Hello gains a sixth component, a wire change under the pre-GA ruling. The merge is one peer's word within the cluster's shared-secret trust domain.
