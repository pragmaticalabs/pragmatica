### Added (2026-10-23 — #2378: JSON options and named codecs for slice HTTP routes)
- **Deploy-time JSON options.** `JsonOptions` (empty-`Option` inclusion, unknown and duplicate key refusal, depth, string, number and document limits) applies alike to generated codecs (`<Type>Json.codec(options)`, `JsonTypeCodec.withOptions`) and to the Jackson mapper (`JsonMapper.jsonMapper().withOptions(...)`), so both accept, refuse and write the same documents. `[verified: integrations/serialization/json-tests/src/test/java/org/pragmatica/serialization/json/tests/OptionsConformanceTest.java]`
- **Build-time naming and renames.** `-Ajson.naming=snake_case` (also `kebab_case`, `pascal_case`) for `@Json` types, `[json] naming` in a slice's `routes.toml` for its route codecs and their Jackson fallback, and `@JsonName` on a record component or enum constant. `[verified: integrations/serialization/codec-processor/src/test/java/org/pragmatica/serialization/codec/JsonNamingTest.java, jbct/slice-processor-tests/src/test/java/com/example/jsonoptions/GeneratedJsonOptionsRouteTest.java]`
- **`[json]` for slice HTTP routes.** Every slice with routes provisions its JSON codec settings implicitly from a `[json]` configuration section: named codecs under `json.codecs.<name>` (`implementation = "generated" | "jackson"` plus the options) and `json.default` choosing one. Without `[json]` keys nothing changes. A present section is validated strictly and reports every fault; `json.naming` is refused because naming is build-time. `[verified: aether/resource/api/src/test/java/org/pragmatica/aether/resource/json/JsonSectionBinderTest.java]`
- **Live switch.** A committed `json.*` change reaches the slice's routes without a redeploy; each request decodes and encodes with the one codec it started with. An invalid change keeps the previous selection and raises the operator event `json-config-rejected` (CRITICAL) once, closed by `json-config-applied`. Configuration-store `json.*` keys are cluster-wide: they apply to every routed slice. `[verified: aether/resource/json/src/test/java/org/pragmatica/aether/resource/json/LiveJsonCodecSettingsTest.java, aether/http-routing-adapter/src/test/java/org/pragmatica/aether/http/adapter/SliceRouterSingleSelectionTest.java]`
- **Maps keyed by value objects and enums in the combinators.** `JsonTypeCodec.mapOf(KEY, values)` with the `KEY` of an `@Json` enum or value object over a `String`, writing and reading keys as the generated map code does. `[verified: integrations/serialization/json-tests/src/test/java/org/pragmatica/serialization/json/tests/CombinatorAgreementTest.java]`
