### Added (2026-11-11 — #3021: Ember JUnit 5 extension, step 2: port allocator)
- **Ember port allocator** (`org.pragmatica.aether.ember.ports`, part of #3021). Per-port claims in a JVM-wide registry, then byte-range locks in one lock file (`/tmp/aether-ember-ports/ports.lock`, directory 1777, file 0666, override `-Daether.ember.portLockDir` / `AETHER_EMBER_PORT_LOCK_DIR`), then a bind probe. An unopenable lock file refuses the claim (never proceeds unlocked); a slot pool above 28 slots is refused naming both numbers; the back-off budget is per claim; a bind collision retries on a fresh block and is counted. `claims(OFF)` turns off registry and locks together for probe red arms. [mechanism: registry within a JVM, fcntl record locks across processes] [verified: `CrossProcessDisjointnessReaderTest`]
