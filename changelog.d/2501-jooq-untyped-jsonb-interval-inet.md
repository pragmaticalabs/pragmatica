- **Selecting an untyped field over a `jsonb`, `interval`, `inet`, `jsonb[]`, range, `xml`, `money` or `bit` column failed through the jOOQ connectors.** The driver's by-type read (no target, or the `Object` target jOOQ asks for) now returns the server's own text for every column type it has no Java type for, instead of refusing it; jsonb, interval, inet and the rest read as `String` (an `inet` or a range has no lossless Java type in the driver, and an interval carries months and days) `[verified: PgAsyncRowObjectTargetTest, UntypedTextReadTest, R2dbcJooqConnectorLiveQueryTest, AsyncJooqConnectorLiveQueryTest]`.
