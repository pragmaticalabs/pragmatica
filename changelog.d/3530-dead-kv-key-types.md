### Removed (2026-11-21 — #3530: four persisted key types were never written or read)
- **Breaking: `JoinDeadlineKey`, `DrainDeadlineKey`, `WorkerSliceDirectiveKey` and `ClusterPhaseKey` are deleted, with their values `JoinDeadlineValue`, `DrainDeadlineValue`, `WorkerSliceDirectiveValue` and `ClusterPhaseValue`** (#3530). No production code wrote or read any of them; the only references were the exhaustive classification switches (`ReplicaFilter`, `WorkerMetadataIndex`), the test that listed `WorkerSliceDirectiveKey` among the runtime keys, and the wire tag pins. The `ClusterPhase` enum stays: the status endpoint and the topology manager use it, derived by `ClusterPhaseView`.
- **Wire:** the eight tags (keys 1098, 1104, 1111, 1137; values 1612, 1618, 1625, 1658) stay pinned in `SystemTags` as retired, so they are never reused, and `WIRE_GENERATION` moves from 6 to 7 because the baseline loses their TAG and SHAPE lines. A node of an older build that receives one of these tags fails it as an unknown tag. None of the four was ever a backed-up key, so no backup holds one; a backup line naming one is refused `UnrecognisedKey`.
