### Changed (2026-10-19 — #2226: generated JSON codecs for slice payloads, replacing the Jackson path)
- **Terra routes now use the same JSON wire form as Aether.** Terra builds each request's context from the router's codec, which is the generated codec where the slice has one, and falls back to `JsonMapper.valueObjectJsonMapper()`. A nested value object is therefore the bare form in both directions, and a response echoed back as a request body decodes. Terra's rc5 object form for a nested value object (`{"code":{"value":"x"}}`) is dropped and refused with 400. Routes that carry no nested value object are unchanged on the wire. `[verified: terra/http/src/test/java/org/pragmatica/terra/http/TerraJsonBodyTest.java]`
