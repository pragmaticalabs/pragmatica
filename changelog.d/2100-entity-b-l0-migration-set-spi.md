### Added (2026-11-14 — #2100 E-B L0: migration-set SPI, `PgSchemaName`, connector eviction)
- **`resource-api` gains the migration-set SPI and `PgSchemaName`** (#2100). `ResourceMigrationSet`, `MigrationSetId`, `MigrationTarget` and `RenderedScript` (package `org.pragmatica.aether.resource.migration`) describe a library's append-only schema scripts; `PgSchemaName` is a parsed PostgreSQL schema name (`[a-z_][a-z0-9_]{0,62}`, always double-quoted when rendered). `pg_*`, `information_schema` and `public` are refused; refusing `public` is a marked guess pending the owner.
- **`DatasourceConnectionProvider` gains `connector(cacheKey, configSection)` and `release(cacheKey, configSection)`** as default methods that serve the section, so existing implementations keep their behaviour. The built-in provider overrides both and now **evicts a failed connector**: a failed creation is no longer replayed to every later caller of the same key. [verified: `DatasourceConnectionProviderEvictionTest`, `PgSchemaNameTest`, `MigrationSetSpiTest`]
