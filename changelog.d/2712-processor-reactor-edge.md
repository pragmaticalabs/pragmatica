### Fixed (2026-11-06 — #2712: example modules intermittently failed to resolve slice-processor under -T)
- **Example slice modules could compile before the annotation processors were installed** (#2712). `annotationProcessorPaths` adds no reactor ordering edge, so a parallel build could fail with `Resolution of annotationProcessorPath dependencies failed ... slice-processor ... absent`. The banking, ecommerce and notification-hub slices and `terra/example-apps` now declare `slice-processor` and `jbct-async-check` as `provided` dependencies, which gives Maven the edge without changing the runtime classpath.
