### Fixed (2026-11-19 — #2644: Rabia decision latency was always recorded as 0)
- **Rabia reports a real decision duration** (#2644). `RabiaEngine.commitDecision` passed a hard-coded `0` to `ConsensusMetrics.recordDecision`, so the average decision latency every consumer read was 0. Each slot now stamps the local monotonic time at which this node first held it, and the decision records the nanoseconds elapsed from that stamp. [verified: `RabiaEngineTest$DecisionLatency` (red on the old constant)] A slot this node never held (first seen as its own Decision, or replayed from the buffer) records no duration sample, so it cannot drag the average toward 0, but it is still counted: `consensus_decisions_total` counts every applied decision, and the average is taken over the decisions that carried a duration (`ConsensusMetrics.recordDecision` counts, the new `recordDecisionDuration` samples).
