### Security (2026-10-18 — #2250: multipart errors answered 500 and leaked exception text)
- **A multipart failure answered 500 with the decoder's exception text in the body** (class names, `nameAttribute is null`, stack frames). `MultipartError` now declares its status: 415 when the request is not multipart on a multipart route, 400 when the body is malformed, and 500 only when a well-formed body could not be read on this side. The client sees a fixed message, and the decoder's exception goes only to the server log. Applied on both paths: `Route.withMultipartBody` and the adapter's `ErrorMapper.defaultMapper`.
