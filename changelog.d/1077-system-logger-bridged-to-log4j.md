### Fixed (2026-09-14 — #1077: `System.Logger` lines from nine production classes never reached the node's log4j)
- **Nine main-source classes log through `System.getLogger(...)`** (JDK Platform Logging) — `ResourceFactory` (the #891/#893 "no close convention" outcome), `SpiResourceProvider`, `SliceLoadingContext`, `SecurityPolicy` (a WARNING when an unrecognised policy defaults to `API_KEY`), `JdbcSqlConnector`, `JdbcJooqConnector`, and three `aether-stream` classes. The node shipped `log4j-slf4j2-impl`, `log4j-core` and the JSON template layout but **no `log4j-jpl`**, so `System.Logger` bound to the JDK default, `java.util.logging`: DEBUG/TRACE from these classes was dropped by JUL's INFO root before log4j ever saw it, and WARNING/ERROR went to stderr in JUL's own format, outside the JSON layout a log pipeline keys on. A diagnostic nobody can read is indistinguishable from no diagnostic.
- **Fix chosen: bridge, not rewrite.** `org.apache.logging.log4j:log4j-jpl` (version managed at the root beside `log4j-slf4j2-impl`, `runtime` scope in `aether/node`) routes every `System.Logger` — the nine classes and any library or future site — into the node's log4j configuration, under the class's own logger name, at the same level. Rewriting nine sites to SLF4J would fix nine sites and leave the mechanism, and `aether/resource/api` deliberately carries no SLF4J dependency. The shaded `aether-node.jar` carries the bridge's six classes and its `META-INF/services/java.lang.System$LoggerFinder` (the `ServicesResourceTransformer` merges it), so the deployed artifact is bridged, not only the test classpath. [verified: `SystemLoggerBridgeTest` (`aether/node`) — a log4j capturing appender on the `ResourceFactory` logger; the real default `close` dispatch on a resource with no close convention emits its `System.Logger` DEBUG line and exactly one log4j event arrives at `DEBUG`; without the dependency (the base) the same run captures 0 (`Expected size: 1 but was: 0`); a control through a log4j logger of the same name proves the appender is wired before the claim is read]
