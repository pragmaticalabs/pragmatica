### Added (2026-11-20 — #3515: tripwire pinning the segments production seals to plain bytes on disk)
- **`StreamSealerOnDiskTripwireTest`** (node) takes the sealer that `StreamAssembly.streamReplication` hands to the partition manager under the default profile, seals records through it, reads the block file the disk tier holds as raw bytes, and fails, naming #3515, unless the file starts with the plain identity header and ends with the plain serialized records (an LZ4-framed or encrypted block does neither). The four silent fallbacks in the sealed-segment path (compress, decompress, unknown codec ordinal, decrypt) stay unreachable only while that holds; the fallbacks themselves are not fixed here.
