### Fixed
- HTTP/1.1 server startup refuses a TLS configuration that fails to build instead of silently opening a plain-text listener on the TLS port, and reports the actual bound port when configured with port 0. A node whose TLS configuration is broken now fails to start (HttpServerError.TlsFailed, logged at ERROR) rather than serving HTTP.
- Certificate rotation of the management and app-http listeners builds the new TLS material before touching the running listener. A bundle that does not build is refused (`HttpServerError.TlsRotationRefused`), the listener keeps serving its current certificate over TLS, and the refusal is an operator event (`http-tls-rotation-refused`, once per transition) with a recovery event (`http-tls-rotation-restored`). Previously the listener was stopped and restarted in plain HTTP.
- `Server.server(...)` in `integrations/net/tcp` refuses to start (`TlsError.ServerTlsRefused`) when its server or client TLS configuration cannot be built, instead of running in plain text.
- HTTP/3 listeners (management and app-http) refuse to start when their QUIC TLS context cannot be built, instead of `start()` reporting success with no listener. A rotation is also refused when the private key does not match the certificate (each half valid on its own previously passed every check, then the new listener completed no handshake).
- A private key that does not match its certificate is refused wherever a TLS context is built from an identity: HTTP/1.1 and HTTP/3 startup, certificate rotation, and the cluster QUIC server/client built at renewal (`TlsError.KeyDoesNotMatchCertificate`, checked inside `TlsContextFactory` and `QuicSslContextFactory`). A key the check cannot read (encrypted, unusual PEM layout) is let through with a warning.
- A refused cluster certificate renewal (the renewed bundle does not build into the cluster QUIC server and client contexts, or its key does not match) is an operator event, `cluster-tls-renewal-refused`, raised once per transition, with `cluster-tls-renewal-restored` when a later renewal is accepted. Previously it was a log line only.
