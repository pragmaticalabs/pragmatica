### Fixed (2026-11-10 — #2982: plain-interface steps were listed as slice dependencies)
- **A plain-interface step (a non-`@Slice` interface with a static factory) is no longer listed as a slice dependency.** The slice manifest (`dependency.N.*`) and therefore the `[slices]` section of `META-INF/dependencies/<Factory>` now name only real slice dependencies, so the cluster no longer tries to resolve slices that do not exist. One predicate, `DependencyModel.isSliceDependency()`, now classifies for the manifest, the factory and the Terra descriptor generators, so they cannot disagree.
