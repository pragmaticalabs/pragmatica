### Added (2026-11-06 — #2762: the FSM2 deployment engine runs on workers)
- **A worker runs the FSM2 node state machine** (#2762, #2757; FSM replacement F3). Under the FSM2 engine a worker now gets the node half of the engine: its goals (`SliceDesiredKey`) and the observed rows (`SliceObservedKey`) reach it over the replica feed, the passive-client switch is its entry edge, a re-subscription's replayed install is stepped as facts (deduplicated by revision), the config hook reaches it, and its write-attempt bound follows the forwarder's timeout. Before this a FSM2 worker ran no deployment engine at all. The cluster state machine stays core-only.
