### Added (2026-10-07 — Terra standalone compilation target)
- **Terra builds unchanged slice sources for a single JVM**, sharing analysis, injection, interception, and routing with the Aether processor. Catalog and ecommerce PricingService compile in a separate Terra example module. [mechanism: `slice.target=terra`, `terra/examples/pom.xml`]
- Blueprint-selected construction validates the dependency graph and owns scoped resource cleanup. Ephemeral in-process pub-sub waits for all subscribers and drains accepted deliveries before shutdown. [verified: `terra/runtime/src/test/java/org/pragmatica/terra/TerraApplicationTest.java`, `terra/runtime/src/test/java/org/pragmatica/terra/TerraTopicsTest.java`]
- Generated direct calls retain LOCAL cache interception; generated publishers/subscribers deliver through the application runtime. Existing Catalog routes execute against a Terra-created slice. [verified: `terra/examples/src/test/java/org/pragmatica/terra/example/TerraExamplesTest.java`]
- Terra startup loads exploded blueprint migrations, retains blueprint ownership, serializes attempts, and waits for connector cleanup before slice construction. The unchanged InventoryService executes against real PostgreSQL; tests cover restart, checksums, ownership, and transactional rollback. [verified: `terra/examples/src/test/java/org/pragmatica/terra/example/TerraDatabaseTest.java` — local PostgreSQL, single process]
- Production HTTP hosting and distribution assembly remain subsequent milestones.
