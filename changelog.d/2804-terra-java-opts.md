### Added (2026-11-24 — #2804: Terra launcher: no JVM-options hook (JAVA_OPTS), so heap and GC cannot be set without bypassing bin/terra)
- **`bin/terra` and `bin/terra.cmd` now honour `JAVA_OPTS`**, placed after `--enable-preview` and before `-cp`; unset or empty adds no argument. The Unix launcher splits on whitespace with no quote parsing and no `*` expansion (an option containing whitespace goes through `JAVA_TOOL_OPTIONS`); `TERRA_OPTS` is deliberately absent because the `TERRA_` environment prefix belongs to slice configuration. [verified: terra/maven-plugin/src/test/java/org/pragmatica/terra/maven/LauncherTest.java] for the Unix launcher (stub `java` argv, real JVM `-Xmx64m -XX:+PrintFlagsFinal`); the Windows launcher is pinned by text only, [design intent — unverified] at runtime.
