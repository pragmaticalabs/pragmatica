### Fixed
- `DeclarativeConsumerPlacementTest$AssigneeMove` no longer reads `-N` redelivered events when the replacement node heals the cluster (#3099). The test summed the consumer counters over `EmberCluster.slicesStatus()`, which is one arbitrary node's view; a freshly joined node answers with an empty view, so every host dropped out of the sum. The post-kill samples are now taken over a complete host set (all survivors plus the replacement, every counter read parsed) in one pass. Test-only; no product change. [verified: red under a mutation that empties the status view for 20 s after a node join (-80, 2 of 3 runs), green under the same mutation after the fix]
