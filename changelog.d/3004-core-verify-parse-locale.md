### Added (2026-11-11 — #3004, #3005, #3006: required/forbidden Option checks, strict decimal parsing, Unicode length predicates)
- **`Verify.ensureSome` and `Verify.ensureNone`** (#3004). `ensureSome(option, predicate, cause)` is the required-field counterpart of `ensureOption`: an absent value fails with `cause`, a present value failing the predicate fails with `cause`, otherwise `Success(value)`. Overloads: binary and ternary predicates with their parameters, and provider forms `ensureSome(option, predicate[, params], absentCause, Fn1<Cause, T> provider)` where the provider builds the failure of a present-but-invalid value from that value. `ensureNone(option, cause)` / `ensureNone(option, Fn1<Cause, T>)` return `Result<Unit>` and fail when the value is present (the provider sees the unexpected value).
- **`Number.parseUnsignedDecimalLong` / `parseUnsignedDecimalInt`** (#3005), each with a `Cause` overload. They accept ASCII `0`-`9` only (leading zeros allowed): `+5`, `-1`, `" 5"`, Arabic-Indic and fullwidth digits, the empty string, `null` and values above `MAX_VALUE` all fail.
- **`Is.codePointsBetween(value, min, max)` and `Is.utf8LengthAtMost(value, max)`** (#3006). Code points count a surrogate pair once; the UTF-8 length counts 1/2/3/4 bytes by code point range (a lone surrogate counts 1, the JDK encoder's `?`).

### Fixed (2026-11-11 — #3013, #2974: locale-independent case folding)
- **Case conversion that compares or keys on its result no longer depends on the default locale** (#3013, #2974). Under a Turkish or Azeri default locale `toLowerCase()` turned `I` into dotless `ı` and `toUpperCase()` turned `i` into `İ`: `Email.email("user@MAIL.COM")` produced the domain `maıl.com`, a `pool_scope = "slice"` enum config key failed to bind, `"BUILTIN"` repository types and `"active"` slice states were not recognised. Every `toLowerCase()` / `toUpperCase()` / `String::toLowerCase` / `String::toUpperCase` in main sources of core, aether, integrations, jbct and examples now passes `Locale.ROOT` (120 files).
