### Added (2026-11-08 — #2805, #2155: per-route success status and Location)
- **A route declares its success status and `Location` in `routes.toml`.** An inline-table route takes `status` (one of `200`, `201`, `202`, `203`, `204`) and `location`, a template whose `{field}` placeholders name components of the result record (an `Option` result is read inside); each field is rendered as one percent-encoded path segment, and a value-object field through its `valueMapping().lower()`. `create = { route = "POST /articles", status = 201, location = "/articles/{slug}" }` answers `201` with the body and `Location: /articles/<slug>`. A `201` with no `location` sends no header. A route that declares neither generates the source it always did. [verified: `jbct/slice-processor-tests` `GeneratedSuccessStatusRouteTest` (the generated router of a real slice)]
- **A `Unit` result answers `204` with no body**, or the declared status (`202` for accepted work); before, it answered `200` with the serialized `Unit`. **An empty `Option` answers `404`** with the RFC 9457 body, and a present one answers its value. [verified: `GeneratedSuccessStatusRouteTest`]
- **A null success value is a JBCT violation, answered `500` and logged at WARN naming the route.** It used to answer `204`. [verified: `GeneratedSuccessStatusRouteTest` `nullSuccess_answers500_andWarnsNamingTheRoute`]
- **Build errors:** `status = 204` on a result that is not `Unit`, a status outside the accepted set (or written as a string), and a `location` placeholder that names no component of the result record each fail the build with a message naming the route. [verified: `SliceProcessorTest` `status204_onNonUnitResult_failsTheBuild`, `nonSuccessStatus_failsTheBuildWithAClearError`, `stringStatus_failsTheBuildWithAClearError`, `locationNamingAnUnknownField_failsTheBuild`]
- The same router answers on Terra and Aether; a forwarded Aether request is answered by the router of the node that runs the slice, which carries the declaration with the route. [mechanism: `AppHttpServer.serveForwarded` dispatches to the local `SliceRouter`; `HttpRoutePublisher.wrapHandler` and `TerraHttpRoutes.secure` carry `successSpec`]
