### Changed (2026-11-21 — #3303: granted management routes receive the request's `Authenticated`, and an ADMIN grant lives only inside a per-request scope)
- **Behaviour change: an ADMIN grant minted at the credential match is live only for the request that matched it.** The management server opens a request scope before validation, on the local and the forwarded path, and hands the validated `Authenticated` to a granted route as an argument; the grant is dead once the request returns, is refused or throws, in any async continuation, and on any other thread, so a granted route checks `live()` synchronously before going async. With `security_mode = "none"` no grant is minted, and a viewer or unauthenticated request never receives one [verified: `ManagementServerSecurityCouplingTest`, `ManagementRouterGrantedHandlerTest`].
