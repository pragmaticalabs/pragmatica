### Fixed (2026-10-12 — #2167: `RabiaEngineSlowApplyDiagnosticsTest` red in CI when the stack sample landed in a lambda bootstrap)
- **Test race, no production change.** The blocking task counted its latch down and then reached a lambda call site; on a cold, loaded JVM the first lambda spends seconds in class generation, so a sample taken then showed the JDK's bootstrap frames instead of the blocking call (CI run 38189775550).
