### Fixed (2026-11-24 — #3635: consensus QUIC leaked owned event-loop groups)
- **A failed QUIC bind or start releases the event-loop groups it created, and certificate rotation no longer replaces the dial client** (#3635). `QuicClusterServer` terminates its owned group (bounded) before reporting `BindFailed`, never a supplied one; `QuicClusterNetwork.onStartFailed` releases the just-built server and client before the failure is reported, so a retry cannot orphan them; `rotateCertificate` keeps one client (and its group and datagram-channel map) and swaps only the TLS context for later dials, which keeps the documented "dialed connections outlive a rotation" behaviour. [verified: `QuicClusterServerBindFailureTest`, `QuicClusterNetworkLifecycleTest` (failed-start, retry, rotation arms)]
