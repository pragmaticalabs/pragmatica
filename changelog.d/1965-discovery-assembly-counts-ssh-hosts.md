### Fixed (2026-10-18 — #1965: bootstrap discoveryAssembly counted role.count() only, so SSH hosts=[...] core sources were invisible)
- **A cloud core source next to an SSH core source declared with `hosts=[...]` took the discovery path.** `BootstrapPhaseDeploy.discoveryAssembly` sized a core source by `count` alone, so a hosts-declared source looked coreless and the cluster was treated as one-source: install-only user data was rendered and the SSH push never gated. A core source is now sized by `count` plus the length of its `hosts` list, the same formula the config module uses, so the two-source cluster keeps the legacy push. `[verified: aether/cli/src/test/java/org/pragmatica/aether/cli/cluster/BootstrapPhaseDeployFormationLabelsTest.java]`
