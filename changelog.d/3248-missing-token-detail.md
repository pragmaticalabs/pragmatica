### Fixed (2026-11-24 — #3248: the auth gate named `Bearer` for a missing token)
- **A request with no credential to a JWT-protected route answered `detail: "Authorization Bearer token required"` whatever `auth_schemes` said.** An application configured for the `Token` scheme told its clients to use a scheme it rejects, and the text did not follow the `<field>: <message>` shape of the other failures. The `MissingCredentials` text is now `token: is missing`; the scheme is carried by the `WWW-Authenticate` challenge, which already names the first configured scheme. Aether's `AppHttpServer` answers the same text. [verified: `TerraHttpServerTest#serve_jwtRefusals_challengeNamesTheFirstConfiguredScheme`, `JwtSecurityValidatorTest$MissingHeaderTests`]
