### Added (2026-11-18 — #3392: jbct skeleton prints a source file's types and members with exact ranges)
- **`jbct skeleton [--fields] [--json] <file>...`** prints one line per type and member with its 1-based `startRow:startCol-endRow:endCol` range (end inclusive, from the first annotation or modifier to the closing brace or semicolon), its signature, annotations and the first row of its doc comment, so that a reader can open one method of a large file instead of reading all of it. A file that does not parse gets its position on stderr, exit code 2 and no skeleton. [verified: jbct/jbct-cli/src/test/java/org/pragmatica/jbct/cli/skeleton/SkeletonRangePropertyTest.java]
- **Row numbers count a lone CR as a line terminator** (and CRLF as one), as the Java compiler does: `LineIndex` in the parser, so `skeleton` and the diagnostics that use it agree for CR-only files.
