# cli-docs-gate - waived documentation drift.
#
# Every line here is a CLI invocation element that this repository's documentation cites and the
# shipped CLI does not define. This file is the drift REPORT, kept where it can be worked off - not a
# mute button:
#
#   * a finding that is NOT listed here fails the build, so drift cannot grow;
#   * a line here that matches NOTHING fails the build, so fixing a document forces its line to be
#     deleted. The list can only shrink.
#
# Format, tab-separated:  <repository-relative path>  command: <command path that does not exist>
#                         <repository-relative path>  option: <option> on <command path>
#
# Keyed by path and drift, never by line number: line numbers are tree-scoped and shift under any
# edit above them.
#
# Regenerate candidate lines with:
#   mvn -pl cli-docs-gate test    ->  cli-docs-gate/target/cli-docs-gate/drift-keys.txt
#
# WHY THESE ARE WAIVED RATHER THAN FIXED, and what fixing them requires.
#
# The mechanical drift was fixed in the commit that introduced this gate: `aether blueprint <sub>` ->
# `aether blueprints <sub>` and `aether artifact push` -> `aether artifacts push`, 20 substitutions,
# each verified to name a subcommand that exists. What is left is NOT typos, and that is exactly why
# it is listed rather than guessed at:
#
#   * `aether scale --min/--max/--target-cpu/--target-latency/--cooldown/--auto` - the shipped
#     `aether scale` takes `-n/--instances`, `-p/--placement`, `--wait`, `--timeout`. The documented
#     flags describe AUTOSCALING, which is a feature claim, not a spelling. Deciding whether the docs
#     or the CLI is wrong is a product call.
#   * `jbct init --slice` - the shipped option is `--no-slice`, the INVERSE. Rewriting the examples
#     changes what they tell the reader to do.
#   * `aether blueprint set`, `aether artifact upload` - unlike their siblings above, `blueprints set`
#     and `artifacts upload` do not exist either, so there is no mechanical target to rename to.
#   * The remaining absent commands (`aether aspects`, `aether topic`, `aether forge`, `aether logs`,
#     `aether cluster audit`, `aether workers health`, `aether nodes decommission`, `jbct add`, ...)
#     are surfaces the documentation describes and the CLI never grew.
#
# Roughly 36 of these lines sit in `aether/docs/specs/**`, which this gate deliberately keeps in
# scope: a design record for a shipped feature is making a claim about the surface that shipped.
