# Wire-tag range ledger for SystemTags (#2822). One reservation per line:
#
#   <from>..<to> <owner> <date> <note>
#
# <from>..<to> is an inclusive range of SYSTEM tags; owner is one token (lane or PR); date is ISO (the day
# the reservation was committed); the note is free text. Blank lines and lines starting with '#' are ignored.
#
# Rule: RESERVE FIRST, then ALLOCATE inside the range. A lane commits its ledger line (its own small PR, or
# with the CTO's ack) BEFORE it pins a tag in SystemTags.java. SystemTagsLedgerTest fails a pin that lies
# outside every reservation, and fails two reservations that overlap. A reservation may be wider than what
# is pinned today (the unpinned tail is the owner's); it never overlaps another. SystemTags stays the single
# authority for the numbers: this file says who may take a number, SystemTags says which type has it.
#

# extent actually pinned on 2026-11-07. Numbers inside those extents that are not pinned stay reserved.
